# Política de privacidad de thread-code subtitulos

thread-code subtitulos es una herramienta de uso interno del canal thread code. Su único fin es subir los archivos de subtítulos (.srt) a los vídeos del propio canal en YouTube.

- Datos a los que accede: la lista de vídeos del canal y sus subtítulos, mediante la API de datos de YouTube, con el permiso que concede el propietario del canal.
- Uso: solo para añadir subtítulos a esos vídeos. No se recogen datos de otros usuarios, no se venden ni se comparten con terceros y no se usan para publicidad.
- Almacenamiento: el permiso de acceso se guarda únicamente en el equipo del propietario del canal. Se puede revocar en cualquier momento en https://myaccount.google.com/permissions.
- El uso de la API de YouTube está sujeto a las Condiciones del Servicio de YouTube (https://www.youtube.com/t/terms) y a la Política de Privacidad de Google (https://policies.google.com/privacy).

Contacto: a través de las incidencias (Issues) de este repositorio.
